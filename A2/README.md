# Assignment 2: Linear Classifiers

In this assignment, you will implement various image classification models, based on the SVM / Softmax / Two-layer Neural Network. The goals of this assignment are as follows:
* **Linear Classifiers (SVM & Softmax):** Implement a Multiclass Support Vector Machine (SVM) and a Softmax classifier from scratch. Focus on vectorized gradient computation and numeric gradient checking.
* **Two-Layer Neural Network:** Build a modular two-layer neural network classifier. Understand how a Two-layer Neural Network can approximate an arbitrary function.
* **MNIST Challenge:** Manually set weights for a Two-Layer Network to solve a simple hand-drawn digit recognition task.
* Understand the differences and tradeoffs between these classifiers
* Practice implementing vectorized gradient code by checking against naive implementations, and using numeric gradient checking
